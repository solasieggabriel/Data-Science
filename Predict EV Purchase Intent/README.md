# Predict EV Purchase Intent

An end-to-end machine learning and statistical analysis pipeline identifying key consumer drivers for electric vehicle (EV) adoption using LightGBM and effect size metrics (Cramér's V, Cohen's $d$).

## Dataset Note
The datasets can be download (`train.csv` and `test.csv`) directly from the [Kaggle Playground Series Competition](https://kaggle.com/competitions/playground-series-s6e9).

## File Structure
- `predict_EV.ipynb`: The main Jupyter Notebook containing exploratory data analysis, statistical validation, model training, and submission generation.
- `submission_model_a_6features.csv`: Kaggle test predictions for Model A (6 features).
- `submission_model_b_13features.csv`: Kaggle test predictions for Model B (13 features).
