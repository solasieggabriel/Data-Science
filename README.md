# Data Science & Quantitative Analysis Portfolio

Welcome to my data science repository! This space showcases applied machine learning, rigorous statistical analysis, and data-driven problem-solving across various projects and datasets.

## Repository Structure

- `predict-ev-interest/` — **Predicting Electric Vehicle Purchase Intent**
  - An end-to-end machine learning and statistical pipeline analyzing over 668,000 consumer records. It combines effect size analysis (Cramér's V, Cohen's $d$) with a LightGBM classification model to identify key EV adoption drivers, isolate statistical noise, and generate optimized Kaggle leaderboard submissions (achieving **0.941+ ROC-AUC**).
